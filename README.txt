# 提示词生成器（PromptGenerator）

便携单文件桌面工具：把"填字段 → 拼提示词"固化成模板流程，一键生成标准格式提示词并复制或提交，适合日常使用 AI 工具但不想每次手写提示词的场景。

## 一、项目简介

### 应用场景

- **高频重复的 AI 提问**：写代码、改文档、做翻译、写纪要……把常用套路存成模板，填内容即出成品；
- **沉淀提示词规范**：字段化约束（背景、约束、验收等），保证每次提问信息完整、格式统一；
- **无安装环境**：单个 exe 拷到任意目录或 U 盘即用，数据跟随程序文件，点击即用。

### 功能介绍

- **模板管理**：预置 14 个模板（通用任务 + 13 个日常场景），支持新增、重命名、保存、重置、删除；
- **字段化编辑**：每个模板由若干字段（标题 + 编号条目）组成，支持增删行，空框失焦自动清理；
- **一键生成**：按定稿格式拼接提示词（`## 字段名：` + 编号条目 + 自动标点），可直接使用；
- **两种输出**：「生成并复制」写入剪贴板；「生成并提交」调用 claude CLI 直接生成结果；
- **生成历史**：自动记录，可复制、编辑、删除；编辑历史基于快照，不污染原模板；
- **便捷唤起**：全局热键、托盘图标、单实例唤醒、贴边收起、置顶；
- **便携数据**：`data\` 自动创建于 exe 旁；所在目录不可写时自动回退用户数据目录。

### 界面介绍

| 区域 | 内容 |
|---|---|
| 标题栏 | 拖拽移动窗口；按钮：置顶 📌、设置 ⚙、最小化 –、关闭 ✕（关闭即隐藏到托盘） |
| 模板栏 | 模板下拉框 + 操作按钮（重命名 / 新增 / 保存 / 重置 / 删除） |
| 编辑区 | 字段列表：字段名 + 编号条目（内容框）；字段间隙可插入新字段 |
| 底部 | 「生成并复制」按钮（右侧 ▼ 可切换为「生成并提交」模式） |

### 数据与文件

| 文件 / 目录 | 说明 |
|---|---|
| `data\templates.json` | 模板数据（含预置与用户模板） |
| `data\settings.json` | 设置：热键、贴边收起、最近使用置顶、日志级别、窗口位置记忆 |
| `data\logs\app-日期.log` | 运行日志，按天分文件、保留 7 天；`--debug` 参数临时提升日志级别 |
| `data\crash.log` | 崩溃记录，独立于常规日志，便于排障 |

## 二、鼠标操作方式

### 模板选择与检索

- 点击模板框**文本区** → 清空进入检索 → 输入关键字 → 下拉实时过滤；
- 点击**下拉箭头** → 展开列表 → 点击候选项确认切换。

流程：`点击模板框 → 输入关键字 → 下拉过滤 → 点击候选项 → 切换模板`

### 模板管理

- 重命名：`点击「重命名模板」→ 模板名进入编辑态（全选）→ 输入新名 → 移焦或 Enter 保存，Esc 取消`
- 新增：`点击「新增模板」→ 自动创建并聚焦 → 填写字段内容 → 点击「保存到模板」或按 Ctrl+S`
- 保存：`编辑内容后 → 点击「保存到模板」或 Ctrl+S → 写入当前模板`
- 重置：`点击「重置模板」→ 恢复出厂默认内容（仅预置模板有意义）`
- 删除：`点击「删除模板」→ 移除当前模板`

### 字段与内容编辑

- 字段**间隙**（字段间窄条）悬停 → 显示 `+` → 点击插入新字段；
- **字段名行**悬停 → 显示 `×` → 点击删除该字段（仅剩一个字段时清空而非删除）；
- **内容框**悬停 → 同时显示 `+` 与 `×` → 插入条目 / 删除条目；
- 空内容框移焦 → 自动删除（该字段仅剩一条时保留，作为待填位）。

### 生成与执行

- 复制：`编辑内容 → 点击「生成并复制」或按 Ctrl+Enter → 提示词写入剪贴板 → 自动记录历史`
- 提交：`点击底部按钮右侧 ▼ → 选择「生成并提交」→ 点击按钮左半 → 调用 claude 生成 → 弹窗显示结果`
- 提交功能需先安装并登录 claude CLI（见「使用建议」）；相同内容未改动时重复操作会被拦截，避免重复生成与重复历史。

### 历史记录

- 打开 / 关闭：`点击「历史」按钮 → 面板开合切换`
- 条目操作：`点击历史条目 → 复制 / 编辑 / 删除`
- 编辑历史基于历史快照生成**临时模板**：不覆盖当前模板；未点「保存到模板」时切走即自动清理。

### 窗口与托盘

- **拖拽移动**：按住标题栏拖动；拖到屏幕边缘自动贴边收起，鼠标悬停露出条即展开（设置中可关闭贴边）；
- **托盘图标**：左键单击切换窗口显示 / 隐藏；右键菜单提供「显示 / 隐藏」「退出」；
- **关闭行为**：点击 ✕ 或最小化只隐藏到托盘，程序继续在后台运行；托盘「退出」才真正结束进程。

### 设置

- 入口：`点击标题栏 ⚙ → 打开设置窗口`
- 热键自定义：`点击热键框 → 按下组合键（如 Ctrl+Alt+P）→ 确认保存；取消则还原原热键`
- 开关项：贴边收起；最近使用置顶（最近使用的 5 个模板自动排到下拉列表最前）。

## 三、键盘操作方式

### 全局与窗口

| 按键 | 功能 |
|---|---|
| `Ctrl+Alt+Shift+P`（默认，可在设置修改） | 全局显示 / 隐藏窗口 |
| `Tab` | 按钮间键盘导航（每个按钮聚焦即时显示提示） |
| `Esc` | 逐级退出（见下方层级） |

### 模板框

| 按键 | 状态 | 功能 |
|---|---|---|
| `↓` / `F4` / `Alt+Down` | 显示态 | 展开模板列表浏览 |
| `↓` / `↑` | 列表展开 | 在候选项间移动高亮（不改变输入） |
| `Enter` | 列表展开 | 确认选择并切换模板 |
| 直接输入字符 | 显示态 | 清空进入检索过滤，下拉按包含匹配 |
| `Enter` | 重命名态 | 确认改名 |
| `Esc` | 重命名态 | 取消改名 |

### 内容框

| 按键 | 功能 |
|---|---|
| `Enter` | 在当前条目后新增一条 |
| `Shift+Enter` | 条目内换行（不新增条目） |
| `Enter`（空框内） | 无操作（防止连续误建空条目） |

### 生成与保存

| 按键 | 功能 |
|---|---|
| `Ctrl+Enter` | 生成并复制 |
| `Ctrl+S` | 保存到模板 |

### Esc 逐级退出

`改名态（取消改名）→ 过滤态（清空过滤恢复列表）→ 下拉展开（收起）→ 关闭窗口`

## 四、使用建议

1. **便携使用**：把 `PromptGenerator.exe` 放到任意文件夹或 U 盘，双击即用；数据自动写在 exe 旁 `data\`，不写注册表、无需安装。
2. **「生成并提交」前置条件**：需安装 Anthropic 的 `claude` CLI（确保系统 PATH 中可调用 `claude` 命令）并完成登录；该功能为真实调用，会消耗 claude API 额度。
3. **模板沉淀**：把高频任务固化为模板，并用「约束」「验收」等字段卡住信息完整性，长期提升提问质量与一致性。
4. **放心编辑历史**：编辑历史记录产生的是临时模板，不点「保存到模板」不会改动原模板。
5. **排障**：日志位于 `data\logs`（按天分文件）；以 `--debug` 参数启动可临时提升日志级别；崩溃另记 `data\crash.log`。
6. **首次运行**：单文件 exe 首次启动若被杀毒软件拦截，请在安全中心放行（自包含程序需自解压运行）。

## 五、常见问题（FAQ）

| 问题 | 回答 |
|---|---|
| 能开多个实例吗？ | 不能也不需要：单实例设计，再次启动会自动唤起已运行实例的窗口。 |
| 数据存在哪里？ | 默认 exe 旁 `data\`；若所在目录不可写（如 Program Files），自动回退到 `%LOCALAPPDATA%\PromptGenerator\data` 并迁移已有数据。 |
| 「生成并提交」没反应或报错？ | 确认已安装并登录 claude CLI；再查看 `data\logs` 当日日志定位原因。 |
| 关闭窗口后程序还在？ | 是：关闭只隐藏到托盘，托盘右键「退出」才真正结束。 |
